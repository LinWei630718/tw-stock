# 📈 台灣股票技術分析與量化操盤系統 (TW Stock Pro)

一套專為台灣股市設計的**現代化、高效能、全裝置支援（電腦/平板/手機）的專業金融操盤等級技術分析與量化診斷系統**。

系統整合台灣證券交易所 (TWSE) 與證券櫃檯買賣中心 (TPEx) 即時與歷史行情，提供 60fps 高流暢度互動式 K 線圖表、核心均線與震盪指標（MA5/MA20/MA60、MACD、RSI、KD、布林通道）、大盤技術溫度計看板、AI 多空技術面診斷儀表板、五大即時策略選股、歷史策略回測、自訂 CSV 資料匯入（支援民國年）、全裝置手機版響應式體驗與玻璃擬態錯誤提示系統。

---

## 🌟 核心功能矩陣

### 1. 專業級互動式 K 線圖表 (TradingView Lightweight Charts)
- **多時間週期 (Multi-Timeframe)**：支援 `5分K`、`15分K`、`60分K`、`日K`、`週K`、`月K` 自由切換。
- **均線系統 (MA)**：
  - 核心關注：**MA5 (週線)**、**MA20 (月線)**、**MA60 (季線)**，支援右上角快速勾選。
  - 完整覆蓋：MA10、MA120 (半年線)、MA240 (年線)。
  - **多空排列即時狀態標籤**：即時分析並提示 `🔴 多頭排列 (MA5 > MA20 > MA60)`、`🟢 空頭排列` 或 `🔵 站上月線`。
- **布林通道 (Bollinger Bands)**：20MA 中軌、±2 個標準差上下軌，視覺化收斂與帶寬擴張。
- **十字光標與即時圖例**：鼠標平移即時呈現開、高、低、收、漲跌幅及 MA5/MA20/MA60 最新數值。

### 2. 多重視圖副圖技術指標
- 🌊 **MACD (12, 26, 9)**：快線 DIF、慢線 DEA、紅綠多空柱狀體 (OSC)，波段轉折一目了然。
- 📈 **RSI (6, 12, 24)**：短期與中期相對強弱指標，附 80 超買與 20 超賣基準警戒線。
- 📊 **成交量 (Volume)**：成交量柱狀圖搭配 5 日均量 (VMA5)、20 日均量 (VMA20) 與爆量標記。
- ⚡ **KD 隨機指標 (9, 3, 3)**：台灣標準 RSV 算式，附 80 超買鈍化與 20 超賣反彈參考線。
- 🎯 **乖離率 (BIAS 20)**：量測收盤價與 20 日月線之正負乖離偏離度。

### 3. 📱 手機版專屬響應式體驗 (Mobile Responsive & Touch UX)
- **行動端專屬底欄導航 (Bottom Nav)**：
  - 📈 **圖表 (Chart)**：觸控縮放、平移流暢無阻，全螢幕 K 線與副圖指標。
  - 🧭 **診斷 (Diagnosis)**：一鍵展開雷達評分、多空四維度進度條與技術訊號。
  - ⭐ **自選 (Watchlist)**：隨身切換關注標的與熱門板塊。
  - 🚀 **選股 (Screener)**：手機隨時查看 5 大選股策略篩選名單。
  - 📊 **看板 (Dashboard)**：掌握市場技術溫度計與核心權值股強弱。
- **橫向滑動工具列**：週期按鈕、均線開關、快捷股票標籤支援行動觸控平滑滑動，不破版不擠壓。
- **雙指縮放與單指平移**：原生觸控手勢最佳化，查閱分時行情與歷史長波段極為直覺。

### 4. 🔔 全域錯誤處理與玻璃態 Toast 通知 (Toast Notification System)
- **告別原生阻斷式 alert 彈窗**：全面導入非阻斷式現代玻璃擬態浮動通知 (`Toast.show`)。
- **四種狀態色彩標記**：
  - ❌ `error` (粉紅)：代碼不存在、網路中斷、CSV 欄位缺失詳細說明。
  - ✅ `success` (粉綠)：CSV 匯入成功、自選股加入成功。
  - ⚠️ `warning` (金黃)：檔案格式不符、歷史數據過短預警。
  - ℹ️ `info` (冰藍)：模式切換、股票載入完成提示。
- **後端全域例外捕獲**：FastAPI `@app.exception_handler` 統一包裝錯誤，回傳結構化 JSON，前端自動轉譯為友善指引。

### 5. 📥 智慧型股票 CSV 匯入引擎 (TWSE & Broker CSV Import)
- **相容台灣證券交易所 (TWSE)**：
  - 自動相容證交所官方匯出格式（如 `STOCK_DAY_2330_202408.csv`）。
  - **自動轉換民國年 (ROC Dates)**：如 `113/08/01` 自動轉換為 `2024-08-01`。
  - 相容中文表頭（`日期`、`開盤價`、`最高價`、`最低價`、`收盤價`、`成交股數`）。
- **券商軟體與 Yahoo Finance 格式相容**：自動識別逗號分隔、空白跳過、數值千分位清洗。
- **重複數據與時序去重**：自動按日期嚴格遞增排序並去重，確保 Lightweight Charts 絕對不崩潰。
- **一鍵載入示範資料**：內建台積電範例檔案，可一鍵測試或點擊下載 CSV 格式範本。

### 6. 📊 市場技術溫度計與綜合看板 (Dashboard)
- **大盤技術溫度計 (Market Technical Temperature Meter)**：
  - 0~100 區間指針計量，即時評估全市場技術面氛圍（`極度狂熱`、`多頭主導`、`中立整理`、`空頭籠罩`）。
  - 多空均線比率 (MA5 > MA20 > MA60 佔比)。
  - MACD 正柱動能佔比與全市場平均 RSI 水位。
- **核心權值標的矩陣卡片 (Bellwether Stock Cards)**：
  - 預設收錄 8 檔台股最具代表性標的：台積電、鴻海、聯發科、台達電、廣達、富邦金、長榮、元太。
  - 卡片即時呈現：現價、漲跌幅、成交量 (張)、均線排列狀態、MACD 柱狀體收斂擴張、RSI 狀態與多空綜合分數。

### 7. 🇹🇼 台股在地化專屬設定
- **色彩慣例自訂**：預設「台股紅漲綠跌」，支援一鍵切換「國際綠漲紅跌」。
- **台股 ±10% 漲跌停價格**：即時依照前日收盤價換算今日漲停價與跌停價。
- **上市 (TWSE) 與上櫃 (TPEx) 支援**：支援 `.TW` 與 `.TWO`，如 `2330`、`8069` 等。
- **張數自動換算**：自動將成交股數除以 1,000 換算為台灣投資人習慣的「張數」。
- **快捷熱門股票晶片**：提供 `2330`、`2317`、`2454`、`0050`、`2603`、`2382`、`8069` 快選。

## 🚀 快速啟動指南

### 環境需求
- Python 3.10 或更高版本
- 現代瀏覽器（Google Chrome, Microsoft Edge, Safari, Firefox）
- 支援行動裝置瀏覽器（iOS Safari, Android Chrome）

### 1. 安裝 Python 依賴
```bash
pip install -r requirements.txt
```

### 2. 啟動系統
- **方式一（Windows 一鍵啟動）**：直接雙擊根目錄下的 `start.bat`。
- **方式二（命令列啟動）**：
```bash
python main.py
```

### 3. 開啟操作介面
於瀏覽器網址列輸入：
👉 **http://127.0.0.1:8000**

*(若需在同一區域網路內以手機測試，可在命令列以本機區網 IP 啟動，例如 `http://192.168.x.x:8000`)*

## 📡 REST API 規格文件

| HTTP 方法 | 端點路徑 | 參數 | 說明 |
| :--- | :--- | :--- | :--- |
| `GET` | `/api/search` | `q` (字串) | 搜尋台股代碼或中文名稱（支援 `2330`, `8069.TWO`, `台積電`） |
| `GET` | `/api/stock/{code}` | `interval` (5m/15m/60m/1d/1wk/1mo), `range` (5d/1mo/3mo/6mo/1y/2y) | 取得 K 線 OHLCV 與當日行情摘要（漲跌停、張數） |
| `GET` | `/api/indicators/{code}` | `interval`, `range` | 取得 MA5/20/60、MACD、RSI、KD、布林通道數據 |
| `GET` | `/api/diagnosis/{code}` | `interval`, `range` | 取得 0~100 多空綜合評分、4 維度指標與即時多空技術訊號 |
| `GET` | `/api/screener/{strategy_id}` | `strategy_id` (kd_golden_cross, ma_bullish_breakout, 等) | 執行 5 大技術策略選股掃描 |
| `GET` | `/api/backtest/{code}` | `strategy` (kd_cross, ma_cross), `range` | 執行該個股技術指標歷史回測與勝率試算 |
| `GET` | `/api/dashboard_summary` | 無 | 取得大盤技術溫度計指數與 8 檔核心權值股技術矩陣 |
| `POST` | `/api/upload_csv` | `file` (Multipart FormData CSV) | 匯入自訂股票歷史 CSV 並即時解析繪製全套圖表 |

## 📥 CSV 匯入格式指引

系統支援直接匯入證交所網站下載的 CSV，或券商歷史導出檔。

### 支援之欄位表頭：
- **日期**：支援 `113/08/01` (民國年)、`2024-08-01`、`2024/08/01`
- **收盤價**：`收盤價`、`Close`、`收盤`
- **開盤價**：`開盤價`、`Open`、`開盤`
- **最高價**：`最高價`、`High`、`最高`
- **最低價**：`最低價`、`Low`、`最低`
- **成交量**：`成交股數`、`Volume`、`成交量`

*(系統內建千分位逗號過濾與欄位容錯，缺漏開高低價時會自動以收盤價平滑填補)*

## ❓ 常見問題 (FAQ)

**Q1：為什麼上櫃股票（如 8069 元太）搜尋時需要輸入完整代碼嗎？**  
不需要。您可以直接輸入純數字 `8069`、中文 `元太`，或是帶後綴 `8069.TWO`，系統皆已內建自動識別上市（TWSE）與上櫃（TPEx）市場機制。

**Q2：手機瀏覽時如何切換看盤畫面與技術診斷？**  
手機螢幕（螢幕寬度小於 768px）時，畫面底部會自動浮現手機專屬導航列（📈 圖表、🧭 診斷、⭐ 自選、🚀 選股、📊 看板），單指點選即可在全螢幕圖表與多空診斷面板間秒級切換。

**Q3：若遇到網路連線超時或股票代號輸入錯誤怎麼辦？**  
系統具備全域例外捕獲與 Toast 提示機制，不會中斷當前看盤畫面，右上角（手機端為螢幕頂部）會即時彈出友善的繁體中文錯誤提示與排查建議。
